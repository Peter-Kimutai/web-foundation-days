# Day 8 Reflection

The most difficult concept in this course was system design, particularly understanding how different components work together to build a reliable and scalable application. At first, concepts such as caching, horizontal scaling, database transactions, and API design seemed challenging. I overcame these difficulties by breaking each problem into smaller parts, studying practical examples, and applying the concepts to projects such as QuickNotes and the TicketHub ticketing system. The step-by-step coding, testing, debugging, and documentation process helped me understand not only how systems work but also why particular design decisions are necessary.

Based on the feedback I received on my capstone project, I would improve the clarity and completeness of my system design documentation. In particular, I would make the relationships between the API endpoints, database structure, and application architecture clearer. I would also strengthen my explanations of scalability, security, and error handling to demonstrate how the application would perform under real-world conditions.

Next, I want to learn more about backend development, database optimization, cloud computing, and distributed systems. I am particularly interested in learning how to deploy applications, monitor their performance, secure APIs, and manage databases under heavy workloads. I also want to gain practical experience with technologies such as Docker, PostgreSQL, and cloud platforms. My goal is to progress from designing systems on paper to building, deploying, and maintaining reliable applications that solve real-world problems.
